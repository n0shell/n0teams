## 🎮 Vista Previa

Una interfaz moderna combinada con una estética retro inspirada en videojuegos clásicos, animaciones fluidas y un diseño completamente responsive impulsado por Tailwind CSS.

---

## ✨ Características

* **👥 Gestión Dinámica de Participantes**: Añade, elimina y reasigna miembros de forma instantánea entre equipos configurables (de 1 a 12 equipos).
* **⚡ Atributos Personalizados (Tipo A y Tipo B)**: Crea categorías únicas con nombre y descripción detallada para asignarlas de forma manual o mediante modales interactivos.
* **🎲 Sorteos y Repartos Aleatorios**: Distribuye participantes por equipos o reparte atributos al azar con un solo clic.
* **💾 Copias de Seguridad JSON**: Exporta e importa configuraciones completas mediante archivos `.json` desde el menú superior desplegable.
* **🔄 Persistencia Local**: Almacenamiento automático en el navegador (`localStorage`) para que nunca pierdas tu progreso.

---

## 🛠️ Tecnologías

* **HTML5** & **Tailwind CSS** (vía CDN)
* **Fuentes Tipográficas**: *Press Start 2P* & *JetBrains Mono*
* **JavaScript (Vanilla ES6+)**: Lógica modular integrada sin dependencias externas

## 🌐 Acceso Rápido

Puedes utilizar la aplicación directamente desde la web sin necesidad de configuraciones previas:

👉 **[Prueba el Panel de Equipos en línea](https://n0shell.github.io/n0teams/)**

Si prefieres ejecutarlo localmente:
1. Clona este repositorio o descarga el código fuente en un archivo `index.html`.
2. Abre el archivo en cualquier navegador.
